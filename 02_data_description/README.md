## Usage

Run from the repository root:

```bash
python 02_data_description/basic_statistics.py
python 02_data_description/long_memory_test.py
python 02_data_description/acf_pacf_plot.py
python 02_data_description/factor_timeseries_plot.py
python 02_data_description/adf_test.py
```

Results are written to `outputs/tables/` and `outputs/figures/`.
