## Usage

Run from the repository root:

```bash
python 06_information_content/factor_loadings_plot.py
python 06_information_content/incremental_correlation.py
python 06_information_content/industry_factors.py
python 06_information_content/incremental_predictability.py
python 06_information_content/standalone_predictors.py
```

Results are written to `outputs/tables/` and `outputs/figures/`.
